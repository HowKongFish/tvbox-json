# TVBox 源（自动验证 · 非商业）

一个不断更新的 TVBox / 影视仓 配置地址。仓库里只有验证过的结果，没有任何影视内容。

**最近一次更新的数据量写在 `merged.json` 的 `version` 字段里。**

---

## 一、地址

    https://raw.githubusercontent.com/<用户名>/<仓库名>/main/merged.json

直接复制这一整行即可。文件更新后即时生效，无缓存延迟。

---

## 二、怎么用

### TVBox / 影视仓 / FongMi（电视、手机、平板通用）

1. 复制上面任意一条地址；
2. 打开客户端，进首页的 **「配置地址」**（有的版本叫「接口」「订阅地址」「数据源」）；
3. 粘贴，点**确定**；
4. 等它拉取完成，回到首页能看到站点列表就是成功了。

> 只支持 `http(s)` 开头的链接。填本地文件路径（`C:\...\merged.json`）是无效的。

### 其他做法

- **想自己挑源**：把这个 json 下载下来，删掉不喜欢的 `sites` 条目，放到自己的静态托管上再导入。
- **想多仓切换**：本仓库只提供单仓合并版；需要多仓看项目里的其他产物。

---

## 三、这个 json 里有什么

- 一批**当前验证为可用**的站点（数量随时间浮动，通常一百多个）；
- 每个站点是标准的 macCMS 采集接口（`type: 0/1`），不含需要客户端内置 spider 的站点；

---

## 四、更新机制

由维护者在本地定时跑验证脚本：采集 → 逐个探测配置与站点 → 失败项降并发复检 → 生成 → 校验 → 只推送这一个 json。

所以：

- 你看不到"更新频率保证"，源掉得快的时候可能一天一更，稳定的时候隔几天；
- 已失效的站点不会立刻消失，但下一次更新会把它们剔除。

---

## 五、常见问题

**导入后站点列表是空的？**
先重新复制一次地址（确认没有多余空格/换行）；再检查客户端是否允许 http 跳转，个别老版本只认 `http`。

**能搜到片但播放失败？**
该站点的点播解析依赖客户端内置 spider，或资源本身挂了。换个站点试，不要在这个站上耗。

**很多站点都失效了？**
源本来就不稳定，等下次更新，或先用别的配置顶着。

**站点里会有广告吗？**
广告由各站点自己控制，本仓库无法干预。
